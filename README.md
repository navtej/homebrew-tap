# Navtej Homebrew Tap

Homebrew tap for Navtej's macOS apps.

## Media Manager

Install directly:

```bash
brew install --cask navtej/tap/media-manager
```

Or tap the repository first:

```bash
brew tap navtej/tap
brew install --cask media-manager
```

Upgrade:

```bash
brew update
brew upgrade --cask media-manager
```
